
# 🍃 TeaHouse — Page d'accueil

## 📌 Présentation

TeaHouse est un site web consacré à la vente de thés, d'infusions et d'accessoires. Cette première page présente la boutique et permet aux visiteurs de découvrir ses produits.

## ✨ Contenu de la page

- Logo et nom du site
- Menu de navigation
- Section de présentation
- Présentation des catégories
- Produits mis en avant
- Pied de page

## 🛠️ Technologies utilisées

- HTML5
- CSS3

## 🎨 Design

Le design utilise des couleurs naturelles inspirées du thé :

- Vert foncé
- Beige
- Crème
- Blanc

La page utilise Flexbox et des media queries pour adapter son affichage aux petits écrans.

## 📁 Fichiers

- `index.html` : structure de la page d'accueil
- `style.css` : mise en forme et design
- 'Images': pour stocker les images utilisés

## 🚀 Comment ouvrir la page

1. Télécharger ou cloner le projet.
2. Ouvrir le dossier du projet.
3. Ouvrir `index.html` dans un navigateur.



## 🎯 Objectif

Créer une page d'accueil simple, agréable et responsive dans le cadre d'un projet universitaire.
